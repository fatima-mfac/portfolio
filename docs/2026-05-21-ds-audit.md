## Notes & caveats

- **Cross-file orphan detection is partial.** Figma's library import remaps variable IDs, so the design file's `boundVariables` references show local IDs that don't directly match the DS file's local IDs. The 24 "orphans" are confirmed unused **inside the DS file**; they may still be referenced by design-file layouts. Pre-deletion needs visual confirmation per token.
- **Variant token audit** used direct `boundVariables` reads (not `get_design_context`) per the known Figma MCP bug that returns base tokens instead of variant tokens.
- **Contrast matrix:** translucent backgrounds (`white-70`) were composited over `background/primary` (slate-100) to approximate real-world conditions. Desktop and Mobile modes hold identical values.
- **Some detached "Header" matches** (e.g. inside `MAC - Equipment Selected Expanded`) appear to be coincidental name collisions inside embedded app mockups, not real DS instances.
